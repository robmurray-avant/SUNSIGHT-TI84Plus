# Original March 1996 *Cruising World* article

William S. Murdock's original TI-81 article is:

**“Create Your Own Sun-Sight Reduction Program,” _Cruising World_, March 1996, pp. 47–50.**

Rather than reproduce copyrighted scans in this repository, use the authorized Google Books archive/search:

https://books.google.com/books?q=%22Create+Your+Own+Sun-Sight+Reduction+Program%22+%22Cruising+World%22

The article contains Murdock's original TI-81 program listing, operating instructions, four test problems, and the calculation sources used at the time.

For additional historical context on Murdock's calculator work, see _The Navigator's Newsletter_, Vol. 2:

https://www.starpath.com/foundation/NN-vol-2.pdf

Copyright in the original magazine article remains with the respective rights holders. This repository therefore links to the online archive rather than redistributing page images.
