# Original March 1996 *Cruising World* article

William S. **Murdoch's** original TI-81 article is:

**“Create Your Own Sun-Sight Reduction Program,” _Cruising World_, March 1996, pp. 47–50.**

Rather than reproduce copyrighted scans in this repository, use the authorized Google Books copy:

https://books.google.ca/books?id=yJv58Lx1rhIC&pg=RA3-PA47

The article contains Murdoch's original TI-81 program listing, operating instructions, four test problems and the calculation sources used at the time.

For additional historical context on Murdoch's calculator work, see _The Navigator's Newsletter_, Vol. 2:

https://www.starpath.com/foundation/NN-vol-2.pdf

Copyright in the original magazine article remains with the respective rights holders. This repository therefore links to authorized online material rather than redistributing page images.
