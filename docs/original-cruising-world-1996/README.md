# Original March 1996 Cruising World article

This folder is for the four page images of William S. Murdock's article **“Create Your Own Sun-Sight Reduction Program,” _Cruising World_, March 1996, pp. 47–50**.

Expected filenames:

- `cruising-world-1996-p47.jpeg`
- `cruising-world-1996-p48.jpeg`
- `cruising-world-1996-p49.jpeg`
- `cruising-world-1996-p50.jpeg`

The images are included in the downloadable repository package accompanying this project. They document Murdock's original TI-81 program, program listing, operating instructions, four test problems, and cited calculation sources.

Copyright in the original magazine pages remains with the respective rights holders. They are included here for historical/reference purposes; if redistribution permission is uncertain, replace the images with bibliographic references or links to an authorized source.
