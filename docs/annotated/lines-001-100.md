# SUNSIGHT — line-by-line annotated source

This is a **documentation companion**, not the file to paste into the calculator. The executable source is `SUNSIGHT.txt`. Each nonblank TI-BASIC line below is followed by its purpose.

The comments deliberately explain both user-interface logic and the Meeus/Bennett celestial-navigation calculations.

## Working-value map

User inputs: `A` year, `B` month, `C` day, `D` UTC hour, `E` UTC minute, `F` UTC second, `G` signed latitude (+N), `H` signed longitude (+E), `I/J` Hs degrees/minutes, `K` limb (1 lower, 2 upper), `L` signed index correction in minutes (+ off arc, − on arc), `M` height of eye metres, `N` pressure mb/hPa, `O` temperature °C. `P` and `Q` are temporary entry/review variables.

`L₁(1)` through `L₁(71)` are working results. Important final values are `L₁(39)` GHA, `L₁(43)` Hc, `L₁(49)` Zn, `L₁(53)` Ha, `L₁(65)` Ho, `L₁(66)` signed intercept, and `L₁(67)` intercept magnitude.
